# Starting a board from a prompt

## Question

You type a prompt into a new board. What happens next?

The pipeline's phase 0 (`brainstorm`, `prototype`) is optional, and `ship` skips phases 0–1 outright when the input is already a PRD. So a start prompt can land at three different stations depending on how sharp it is.

To settle: does the board always start at the interview, always offer a choice, or judge sharpness and route accordingly — and if it judges, what does it show the human so the routing is not a silent decision? Also: what a board looks like in the moments before its first question arrives, and what happens to a prompt that turns out not to be feature work at all.
