# Whole document review

Use this independent broad pass only when the approved plan names it. It complements selected focused personas; it does not repeat them.

1. Read the document as one delivery contract.
2. Look for cross-section contradictions, missing handoffs, impossible verification, or a gap between outcome and work.
3. Respect settled decisions and avoid preference-based alternatives.
4. Return only the few findings that a focused persona is unlikely to catch.

Return only evidence-backed findings. Final synthesis adds them to the document findings schema. Agreement with another route records corroboration but never increases severity or confidence by itself.
